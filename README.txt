MARVEL-INSPIRED STATIC PORTFOLIO — S SRIGANTH

Files:
- index.html : page structure and resume content
- style.css  : responsive styling, red/black cinematic theme and arc-reactor-inspired graphic
- script.js  : mobile navigation and reveal animations

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For editing, open the folder in Visual Studio Code.

No build step or backend is required. Google Fonts require an internet connection; fallback fonts are included.

Notes:
- The design is Marvel-inspired (cinematic red/black, reactor motif), not an official Marvel website.
- Contact details and career details are based on the supplied resume.
- If you add a real profile photo, GitHub, LinkedIn, or project URLs, update index.html.
